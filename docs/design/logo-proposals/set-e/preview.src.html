Pi Workbench 标志方案

标志由三件东西组成：松绿印面上的纸色 π、名字 WORKBENCH、落款 TChen。印面就是应用图标本身， 所以顶栏、文档、头像看到的都是同一枚东西。完整名字 Pi Workbench 只在窗口标题、关于页这类需要点名的地方出现。

主锁定 · Horizontal

印面、WORKBENCH、TChen 依次排开。印面的底边与 WORKBENCH 的基线对齐——像一枚章压在字行上；印面因此比文字高出一截，这是刻意的。

规则 · Notes
对齐
印面底边压在文字基线上，章与字母落在同一条线；不要按中心对齐（印面会下探到字行以下），也不要按行盒底对齐（会低于基线一截）。
印面
印面就是应用图标本身：松绿底、纸色 π，圆角 19.8%（152/768）。顶栏、文档、头像都用同一件东西，不另画一版。π 取自 Noto Serif 的真实轮廓（OFL），不做拉伸。
署名
TChen 永远排在 WORKBENCH 之后，用 Geist Mono、降低一档对比度、前面加 1px 竖线；不放大、不用衬线、不单独作为标志使用。
图标分稿
256 带署名；128 及以下用简化稿。反例在尺寸区里，可以看到署名缩到 40px 会变成灰线。
留白与单色
四周最小留白等于印面高度的一半；单色版把松绿底换成墨色、π 与署名反白，不做描边、投影、渐变。
