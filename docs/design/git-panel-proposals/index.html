Git 面板 · 排版方案

三版主方案，加上分支/工作树分段的样子和一版窄宽降级，面板都是真实尺寸（默认 260px）。共同前提：面板只做索引，提交详情在编辑器区打开；行高、字号、颜色按面板自己的规范走，不套用主界面的 type-* 角色。

左栏是面板本身，右栏是点击提交后编辑器里的样子。Paper / Ink 各一份。

数据为示意，取自本项目最近的提交。
